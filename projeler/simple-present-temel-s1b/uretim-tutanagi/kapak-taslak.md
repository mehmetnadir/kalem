## 2. Yerleşim

```
0 ─────── 280   boş zemin
280 ───── 350   kanal katmanı: logo + @ydspublishing
360 ───── 450   rozet YDT · BASIC
470 ───── 900   başlık: MY BROTHER / GO.   (satır 2 sağ ucunda kırmızı kalem ✗, x ≈ 800–940)
920 ──── 1380   genç figür (ayakta, sola dönük) · sağında otobüs (sola gidiyor)   ← kol a ile aynı
1400 ─── 1550   altyazı bandı (kapak PNG'sinde boş)
1570 ─── 1920   boş zemin
```

- Kapak = videonun ilk karesi. Kapak PNG karesi t 0,90 (kare 27): başlık tam, ✗ çizili, ilk söz (1,00) ve altyazı henüz yok.
- Kalem hareketi: ✗ 0,3–0,8 sn'de kalemle çizilir (kırmızı, `RT.kirmizi`; kol a değer sahnesindeki kırmızı kalem çizgisiyle aynı renk).
  Başka hareket yok.
- Başlık sesten önce gelir: tek istisna (kol a ile aynı). Ses 1,00'de başlığın üç sözcüğünü okur, sonra cümleyi tamamlar.
- Figür ve otobüs etiketsizdir. Uçuşta (1,90–2,45) ✗ başlıkla birlikte söner (kol a `baslik_sol`).
- Kaba boy: `MY BROTHER` 10 karakter → 0,55 em/karakter ile ≈ 163 px'te 900 px'e sığar (ölçülmedi; motor ölçer, üst sınır 190).
  Satır 2 aynı boy. `GO.` ≈ 270 px; sağında ≈ 600 px boşluk ✗'i taşır (sağ sınır 960).
- Glif: Türkçe harf yok; Fredoka 700 latin yeter.
- Neden hap yok: hap `GO.` sözcüğünü vurgular ve kancadaki "Hata nerede?" sorusunun cevabını kapakta verir. ✗ "bu cümle yanlış"
  der; yeri söylemez. ✗ satır 2'nin bitişiğinde değil, satırın sağ ucunda durur (kenar boşluğu işareti gibi).
- **DİKKAT:** kapakta kasıtlı yanlış İngilizce var. ✗ olmadan küçük resim yanlışı doğru gibi gösterir. Bu yüzden ✗ zorunludur; küçük
  resim ölçeğinde (≈ 1/6) görünürlüğü kare çekilince denetlenir (jüri bakacak). Emsal: s3 A kapağı yanlış cümleyi kartta taşır,
  başlığı `BU CÜMLE` / `YANLIŞ` der.

## 3. Kullanılmayan seçenekler

| Seçenek | Neden kullanılmadı |
|---|---|
| `BU CÜMLE` / `YANLIŞ` + kart | s3 A kapağının başlığı ve düzeni; aynı derste iki kapak aynı görünür |
| `HATA` / `NEREDE?` | sesteki soruyu yineler; cümle görünmez, küçük resimde anlamsız (s3 karar notu emsali) |
| `MY BROTHER GO` + ayrı kart | figür + otobüs düzeninden sapar; kanca karesinde ikinci bir fark (yerleşim) açar |
| `HE GO` / `DOĞRU mu?` | sesteki cümlede `he` yok; kapak C `HE GOES` / `I GO` ile karışır |

Kapak C ile ilişki: C doğru çifti (`HE GOES` / `I GO`) gösterir; kol b A yanlışı gösterir. Kol b'nin ilk karesi ile grubun C kapağı
birbirinin cevabıdır; ikisi aynı soruyu sormaz.

## 4. `senaryo.json` alanları (önerilen; sahne istemine girer)

```json
"giris": {
  "logo": "varlik/logo/yds-publishing.svg",
  "satir1": "MY BROTHER",
  "satir2": "GO.",
  "rozetler": ["YDT · BASIC"],
  "sahne": [
    {"figur": "open-peeps/standing-2", "x": 34, "y": 60, "olcek": 0.8},
    {"ad": "bus", "x": 70, "y": 64, "olcek": 0.45}
  ]
},
"meta": {
  "kapak": {
    "satir1": "MY BROTHER",
    "satir2": "GO.",
    "canAlici": "he, she, it fiile s alır; I, you, we, they almaz"
  }
}
```

- `sahne` dizisi kol a ile birebir (figür ve otobüs aynı yerde).
- `meta.kapak.canAlici` ana ders `canAlici` listesinden birebir madde (`canAlici[3]`).
- Hap yok: kol a A sahnesindeki hap çizimi kol b'de ✗ çizimiyle değişir (sahne istemi).
