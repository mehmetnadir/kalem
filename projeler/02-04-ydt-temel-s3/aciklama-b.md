## 4. UTM kuralı

| Alan | Değer |
|---|---|
| `utm_source` | `youtube` · `instagram` · `tiktok` |
| `utm_medium` | `short` (YouTube açıklaması) · `bio` (profil bağlantısı) · `story` (Instagram hikâye çıkartması) |
| `utm_campaign` | `ING-YDT-GR-02-04-T` (ana ders kodu, olduğu gibi; huni-plan §6). S1 küçük harf kullanır: karar Nadir'de |
| `utm_content` | `s3-b` (B seti; A seti `s3-a` → `aciklama-a.md`) |

- `{UZUN_VIDEO_URL}` `watch?v=…` biçiminde gelirse ilk `?` yerine `&` yaz.
- YouTube adresindeki UTM grammar-kapi kayıtlarına düşmez; YouTube tarafını Studio "Trafik Kaynakları" ölçer.
- Profil bağlantısı tektir. A ve B setini sırayla yayınla; profil bağlantısı yayındaki setin `utm_content` değerini taşır.
